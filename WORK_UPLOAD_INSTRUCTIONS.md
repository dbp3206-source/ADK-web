# HOW TO USE WITH GPT WORK

1. Upload the ZIP as the primary project source.
2. Paste the whole `BUILD_PROMPT.md`.
3. Require GPT Work to inspect every file before coding.
4. Request a shareable preview, not production deployment.
5. Review the home thesis, six project vibes, System Explorer, mobile and evidence handling.
6. Return feedback as named change requests.
7. Deploy only after Critical acceptance tests pass.

## Recommended first message
“Use the uploaded build package as the sole approved specification. Build Phase 1–3, create a shareable preview, run the acceptance tests, and report blocked owner inputs without inventing replacements.”

## Add when available
Owner name, email, GitHub, LinkedIn, CV, dossier, six repositories, verified screenshots and commit hashes.

## Do not request
A live backend in the first build; invented source evidence; copied Hallmark/Awwwards layouts; a generic SaaS theme; production deployment before preview approval.
