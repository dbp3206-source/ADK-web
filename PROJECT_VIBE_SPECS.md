# PROJECT VIBE SPECIFICATIONS

## System rule
The portfolio has one design system and six project worlds. Cobalt is the universal action and signal color. Each project gets one supporting accent, a distinct information layout and a unique interaction metaphor. Do not reuse one macro-layout with a new header color.

## 01 — Trip Planner: Cartographic Utility
**Mood:** calm, practical, navigational.  
**Accent:** deep teal.  
**Metaphor:** route line = state trail.  
**Layout:** itinerary canvas plus state inspector.  
**Details:** map-grid lines, day markers, coordinate-like metadata, tool receipts.  
**Interaction:** step through Plan → Save → Retrieve and inspect the state object.  
**Recruiter takeaway:** the project crossed from generation to action and retrievable state.  
**Avoid:** travel stock photos, booking widgets, unverified prices.

## 02 — Script Team: Editorial Redline Studio
**Mood:** disciplined creative collaboration.  
**Accent:** editorial red.  
**Metaphor:** the active role owns the manuscript; critique lives in the margin.  
**Layout:** manuscript, margin annotations and transfer timeline.  
**Details:** revision marks, structured feedback fields, version tabs.  
**Interaction:** Drafter → Critic → Reviser and draft/revision comparison.  
**Recruiter takeaway:** specialization and explicit handoff contracts improve clarity.  
**Avoid:** chat bubbles and playful team avatars.

## 03 — World Cup Analyst: Match Intelligence Desk
**Mood:** analytical, evidence-led, sports newsroom.  
**Accent:** deep pitch green.  
**Metaphor:** evidence ledger and calculation tape feed an analyst report.  
**Layout:** compact scoreboard header, source ledger, calculation notebook, report memo.  
**Interaction:** toggle Fact / Calculation / Synthesis layers.  
**Recruiter takeaway:** tools retrieve facts, code calculates, the root synthesizes.  
**Avoid:** fake live scores, unsupported team marks, unsourced numbers.

## 04 — Love Advisor: Dual-Lens Synthesis
**Mood:** thoughtful, respectful, structured.  
**Accent:** muted plum.  
**Metaphor:** two lenses remain independent until a controlled merge.  
**Layout:** mirrored lanes leading to a central schema.  
**Details:** branch labels, uncertainty markers, safety note, JSON field preview.  
**Interaction:** parallel completion and synthesis gate; never score a person.  
**Recruiter takeaway:** parallel work reduces waiting while ordered synthesis preserves logic.  
**Avoid:** hearts as the main language, appearance scoring, aggressive tone, sensitive-trait inference.

## 05 — Dashboard Insights: Operations Evidence Lab
**Mood:** rigorous, information-dense, controlled.  
**Accent:** dark amber for audit/quality; cobalt remains the active-system color.  
**Metaphor:** a report moves through an evidence laboratory.  
**Layout:** dominant report canvas, ingestion/frame rail, QA/evidence rail.  
**Details:** claim IDs, source references, QA stamps, iteration counter, archive receipt.  
**Interaction:** Ingest → Frame → Write → QA → Revise → Format → Archive.  
**Recruiter takeaway:** trustworthy analysis requires data boundaries, QA, logging and evidence.  
**Avoid:** fabricated KPIs, fake charts, active upload controls in static mode.

## 06 — A2A Orchestrator: Network Control Plane
**Mood:** precise, distributed, infrastructural.  
**Accent:** cobalt.  
**Metaphor:** a request signal crosses service boundaries and returns as an artifact.  
**Layout:** large topology, specialist bank and technical inspector.  
**Details:** ports, Agent Card fields, routing reason, service boundary, fallback status.  
**Interaction:** choose request, watch routing, inspect specialist workflow and artifact return.  
**Recruiter takeaway:** the final project is a system-of-systems, not a larger prompt.  
**Avoid:** fake health lights, invented latency, opaque animations.
