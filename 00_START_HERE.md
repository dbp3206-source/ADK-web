# START HERE — ADK Agent Ecosystem Portfolio

This package is a build-ready handoff for GPT Work, Sites, Codex or a frontend engineer.

## What to send
Upload the entire ZIP package and paste the contents of `BUILD_PROMPT.md`.

## Build target
Create an English-first, evidence-led technical portfolio that explains six AI-agent projects as one architectural progression:

**ACT → DELEGATE → COMPUTE → COMPOSE → VERIFY → CONNECT**

The site must feel like a bespoke technical editorial experience, not a generic SaaS template.

## Non-negotiable rules
1. Build a static evidence-first website before any live-agent backend.
2. Label every architecture playback **“Simulated trace from repository architecture”** until a verified backend exists.
3. Do not invent metrics, repository paths, test results, commit hashes, testimonials, deployment status or live latency.
4. Hide external CTAs when their URL is empty in `config/site-config.example.json`.
5. Preserve the project-specific art directions in `PROJECT_VIBE_SPECS.md`.
6. Build and test desktop, tablet and mobile.
7. Keep evidence and limitations visible.
8. Do not replace the visual direction with gradients, glow, glass cards or a conventional 3×2 project-card grid.

## User inputs still required before public release
- Name, profile headline and contact information.
- CV and portfolio dossier files.
- GitHub profile and six repository URLs.
- Verified source paths, screenshots, tests and commit hashes.
- Confirmation of each project’s implementation status.

The site may be previewed with these items absent, but missing links must be hidden rather than fabricated.
