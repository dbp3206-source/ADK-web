# Design Brief

## Audience and viewing context
Recruiters scanning for scope and progression in 3–7 minutes; hiring engineers inspecting architecture, traces, decisions, failure modes and evidence; learners reading plain-language explanations on desktop, tablet or mobile.

## Core message
Not six chatbots: six architectural steps from one tool-using agent to a distributed agent ecosystem.

## Desired reaction or action
Understand the ACT → DELEGATE → COMPUTE → COMPOSE → VERIFY → CONNECT progression, run a simulated trace, open a relevant case study and inspect evidence and limitations.

## Source authority
All package files in the repository root, `content/*.json`, `config/site-config.example.json`, and both PDFs under `references/`. The package is the sole approved content specification.

## Content hierarchy
1. System thesis and ordered capability ladder.
2. Dashboard Insights and A2A Orchestrator as the deepest proof.
3. Six case-study architectures, decisions and failure modes.
4. Simulation honesty, evidence status and blocked owner inputs.
5. Learning and contact paths.

## Visual territory
Cobalt Technical Editorial: near-white cool paper, near-black ink, cobalt signals, asymmetry, strong index numerals, light rules, minimal shadow and hand-built SVG architecture.

## Brand and system constraints
Use `DESIGN_TOKENS.json`; Space Grotesk display, Inter body/UI and JetBrains Mono metadata through `next/font`; small radii; 4-point spacing; cobalt focus; six supporting project accents. No packaged font files.

## Anti-goals
No generic marketing hero, 3×2 equal project grid, gradient, glow, glassmorphism, AI orb, robot illustration, fake browser chrome, invented evidence, fake metrics, testimonials, live status or production claims.

## Output contract
Static-exportable Next.js App Router site in strict TypeScript; data-driven content; SVG diagrams; six responsive compositions; Vitest, Playwright and axe checks; local screenshots; QA evidence under `design-work/`; Sites saved version only unless preview approval permits deployment.

## Reference interpretation
Borrow Hallmark’s structural variety and anti-template discipline plus the package PDFs’ hierarchy and signal-path metaphor. Do not copy external layouts, code or assets.
