## Projects index intro
These are not six versions of the same chatbot. Each project adds a missing engineering layer and changes who controls the work, what the system can access and how results can be verified.

## Project conclusions
- Trip Planner: An agent needs hands to act and a place to remember.
- Script Team: Do not make one agent endlessly broad; make each role explicit.
- World Cup Analyst: Let tools retrieve facts, code calculate numbers and the model synthesize.
- Love Advisor: Run independent work in parallel, then synthesize in order.
- Dashboard Insights: Trust requires evidence, quality gates and an artifact lifecycle.
- A2A Orchestrator: A2A connects independent systems without erasing their boundaries.
