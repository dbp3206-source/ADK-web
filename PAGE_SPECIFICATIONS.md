# PAGE SPECIFICATIONS

## Global shell

### Header
- Left: wordmark or owner name.
- Right: primary navigation and conditional utility links.
- Editorial line-based active state; no oversized pill nav.
- Mobile drawer uses focus trap, Escape close, scroll lock and focus restoration.

### Footer
- Thesis line, source policy, limitations, conditional contact links, version and last verification date.

### Global states
- Loading only for code-split interactive modules.
- Errors include retry or static fallback.
- Empty states explain the next action.
- Focus uses cobalt ring.
- Reduced motion removes path travel.

---

## Home `/`

**Purpose:** Explain the progression and start the main journey.  
**Primary action:** Run the system trace.  
**Secondary:** Download dossier when configured.

### Sections
1. **Thesis:** asymmetric 42/58 grid; copy left, compact simulated trace right.
2. **Proof strip:** `6 projects / 4 multi-agent patterns / MCP + RAG / A2A ports 8000–8005`.
3. **Capability ladder:** six checkpoints; focus reveals capability, evidence target and main limitation.
4. **Featured deep dive:** Dashboard Insights largest; A2A as tall system panel; four others as editorial index rows.
5. **Request anatomy:** prompt → routing → remote agent → workflow → tool/data → validation → artifact.
6. **Engineering honesty:** represented now vs next production layer.
7. **Contact terminal:** compact terminal-inspired ending.

**Do not:** use a generic hero, a 3×2 project-card grid or an oversized CTA banner.

**Mobile:** stack thesis and trace; vertical ladder; full-width featured sections; no horizontal overflow.

## Projects `/projects`

**Purpose:** Browse and compare architecture patterns.  
**Primary action:** Open a case study.

- Intro thesis.
- Filter chip group with result count and clear action.
- Six project index rows: number, title/lesson, patterns, evidence summary, status.
- Empty state uses approved copy.
- Mobile rows become two-tier blocks.

## Project case study `/projects/[slug]`

Shared information logic, unique art direction.

### Required sections
1. Masthead and thesis.
2. Problem and user job.
3. Architecture with legend.
4. Request trace.
5. Verified code evidence or pending state.
6. Design decisions and trade-offs.
7. Failure modes.
8. Upgrade path.
9. Evidence footer and last verified date.
10. Previous/next capability navigation.

### Unique compositions
- Trip Planner: itinerary canvas + state drawer.
- Script Team: manuscript + margin critique + transfer timeline.
- World Cup Analyst: evidence ledger + calculation tape + report.
- Love Advisor: mirrored parallel lanes + central schema.
- Dashboard Insights: report canvas + QA rail + claim/evidence matrix.
- A2A Orchestrator: topology + routing inspector + Agent Card.

Love Advisor must show a visible safety and uncertainty note.

## System `/system`

**Purpose:** Explain the distributed system through the signature interaction.  
**Primary action:** Complete a request trace.

### Desktop
Topology plus inspector; preset rail; Agent Card opens in inspector, not a large modal.

### Controls
Preset, Play/Pause, Previous, Next, Restart, step counter, text alternative and related project.

### Required label
**Simulated trace from repository architecture**

### Future live failure
Show actual status when verified; keep static architecture and a bounded offline message.

### Mobile
Topology becomes a vertical ordered trace; inspector appears below the active step.
