# USER FLOWS

## FLOW-01 — Recruiter quick scan
Direct entry → thesis → proof strip and capability ladder → Dashboard or A2A deep dive → “What this proves” and limitations → CV/GitHub/contact.

**Fallback:** Missing external links are omitted.

## FLOW-02 — Engineer verification
Open case study → architecture legend → request trace → design decisions → failure modes → evidence footer → repository/test links when available → last verified date.

**Fallback:** Missing evidence is “Needs verification.”

## FLOW-03 — System Explorer
Open `/system` → choose request preset → Play or Next → routing reason → specialist focus → internal workflow → tool/data schema → artifact → related case study.

**Future live error:** Keep the simulated architecture available.

## FLOW-04 — Pattern discovery
Open `/projects` → select filters → review matching rows → open project → return with filters preserved where practical.

## FLOW-05 — Learner path
Open `/learn` → choose 60-second or 5-minute explanation → use glossary → inspect evidence → answer three-question self-check → open related project.

## FLOW-06 — Mobile case study
Open project at 320–414 px → thesis → vertical architecture trace → expandable details → limitations → evidence footer → conditional source/CV action.

## FLOW-07 — Keyboard System Explorer
Tab to presets → activate with Enter/Space → control Play/Pause/Previous/Next → hear `aria-live` updates → inspect nodes and links → open case study.
